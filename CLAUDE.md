# Brawl Guides

Репозиторий для генерации видео-гайдов по Brawl Stars. Пользователь общается по-русски.
Основной сценарий — скилл `guide` (`/guide <бравлер>`), см. `.claude/skills/guide/SKILL.md`.

- Не меняй стиль шаблона `template/video.html` без просьбы пользователя — это его фирменный стиль.
- Информация в гайдах должна быть актуальной: сверяйся с вики (раздел History), а не с памятью.
- `out/` не коммитить (там рендеры и скачанные иконки).
